작성 요청: $ARGUMENTS

위 요청을 바탕으로 블로그 글을 작성하라. `$ARGUMENTS`가 비어있으면 무엇에 대해 쓸지 사용자에게 먼저 물어보라.

완성된 글 전체(제목 → 한 줄 요약 → 소제목별 리스트)를 반드시 최종 응답 텍스트에 그대로 출력하라 — 메모리 파일 목록이나 작업 요약만 남기고 본문을 생략하지 않는다. 소설·에세이식 서술, 1인칭 경험담, 해시태그는 쓰지 않고, 근거를 확인한 정보만 리스트로 정리한다. 참고 영상/자료 경로가 있으면 먼저 읽어 근거를 확인하라.
